Invoice Studio website screenshots
=================================

The homepage gallery uses the files in:
- images/invoice-studio/android/
- images/invoice-studio/windows/

They are actual application screenshots supplied for the YG-Tech website.
The gallery opens full-size images through gallery.js.

Easy replacement:
If a newer screenshot should replace an existing one, overwrite the image with
the same filename. The homepage HTML will continue to work without changes.

Android gallery filenames:
- welcome-language.jpg
- customer-management.jpg
- business-setup.jpg
- currency-selection.jpg
- create-invoice.jpg
- export-and-print.jpg

Windows gallery filenames:
- dashboard.png
- new-invoice.png
- invoice-workspace.png
- generated-pdf.png

Note: screenshots containing a visible third-party stock-image watermark were
intentionally not included in the public gallery.
